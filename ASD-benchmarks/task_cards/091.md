# P100-091: Measurement dataset and analysis code for "Measurement-Driven Modeling of End-to-End Latency in an Indoor Private Standalone 5G Network"

How do location and traffic conditions affect latency distributions across repeated private-network tests?

## Source

https://researchdata.tuwien.ac.at/records/hja53-s8y18

## Source version

1.0.0

## Origin

measured_or_observed

## Measurement dates

June 3–July 3, 2025; dataset released September 2026.

## Variables and units

latency, throughput, target rate and raw iPerf logs

## Independent units

location and complete run, invalid clocks retained

## Validation design

location and complete run, invalid clocks retained Verify identifiers before allocating groups; the partition is not executed or frozen by this acquisition.

## Source preprocessing

All 245 raw runs and source processed tables/code. Three invalid one-way-delay runs are retained and flagged; processed tables replace them with cell means.

## Prior analyses and limitations

Hold out locations or whole runs. Fit against achieved throughput, not only target rate. Raw and imputed versions must not be mixed without disclosure. 

## Missingness

Native blanks, sentinels, absent records and source quality flags are preserved. No imputation performed by the curator. Exact missingness semantics come from source dictionaries/headers; no universal missing-value rule is imposed.

## Calibration

Use the retained source calibration files/standards and instrument metadata where provided. Absence of an explicit calibration record is not replaced by an assumed calibration.
