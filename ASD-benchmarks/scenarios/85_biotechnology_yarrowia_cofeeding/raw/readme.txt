Cultures were grown in YNB medium (0.17% yeast nitrogen base, 0.5% NH?Cl, 50?mM phosphate buffer, pH?6.8) at 28?°C and 200?rpm. Dry cell weight was measured by lyophilization. EG and GA toxicity was assessed by supplementing cultures with 15–60?g/L and monitoring OD???.Metabolite quantification (glucose, EG, GA, acetate) was performed via HPLC (Shimadzu Nexera Lita) using a Resex ROA-Organic Acid H? column and dual detection (UV 210?nm and RID). RNA-seq analysis was conducted on cultures grown with acetate alone or acetate + EG. RNA was extracted, quantified (NanoDrop), and sequenced (Illumina NovaSeq 6000) after library prep with the Illumina Stranded mRNA Kit. Stable isotope labeling experiments used ??C-labeled EG and acetate to trace carbon incorporation into GA and amino acids. GC–MS analysis (Agilent 8890/5977C) was performed on derivatized supernatants and hydrolyzed cell pellets. Mass isotopomer distributions were processed using PIRAMID software, and Summed Fractional Labeling (SFL) was calculated to quantify substrate contribution to biosynthesis. These labeling data and uptake rates were integrated into the 13C-metabolic flux analysis, which was performed using a stoichiometric model encompassing central carbon metabolism in Yarrowia lipolytica, including pathways such as the TCA cycle, glyoxylate shunt, gluconeogenesis, and amino acid biosynthesisMethods for processing the data: Raw HPLC data were processed using Shimadzu LabSolutions software for peak integration and quantification. RNA-seq reads were trimmed and aligned to the Y. lipolytica CLIB89 W29 reference genome. Gene expression was quantified using featureCounts (Subreads v2.1.1), and statistical analysis was performed in R (v4.3.3) with Benjamini-Hochberg correction. Gene Set Enrichment Analysis was conducted using the FunFea R package. GC–MS data (.cdf format) were processed using PIRAMID, a MATLAB-based tool for isotopologue integration and correction for natural isotope abundance. 13C-metabolic flux analysis was performed using INCA software. Instrument- or software-specific information needed to interpret the data: Environmental/experimental conditions: Describe any quality-assurance procedures performed on the data:
