# P100-091: Measurement dataset and analysis code for "Measurement-Driven Modeling of End-to-End Latency in an Indoor Private Standalone 5G Network"

How do location and traffic conditions affect latency distributions across repeated private-network tests?

Source: https://researchdata.tuwien.ac.at/records/hja53-s8y18

Version: 1.0.0

Measurement coverage: June 3–July 3, 2025; dataset released September 2026.

Data origin: measured_or_observed

Source processing: All 245 raw runs and source processed tables/code. Three invalid one-way-delay runs are retained and flagged; processed tables replace them with cell means.

Interpretation limits: Hold out locations or whole runs. Fit against achieved throughput, not only target rate. Raw and imputed versions must not be mixed without disclosure.
