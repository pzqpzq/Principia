1. Title of Dataset: Rheological_data
Data were collected in the Warsaw Univesity of Technology, Faculty of Chemistry

2. Folder List: 

Folder Rheological_data contains 3 sub-folders: flow_data, amplitude_sweep, 1st normal stress difference. Each folder contains 
a data file for all experimental sets:

AS35 XG0.5.csv
AS35 XG1.csv
AS35 XG1.5.csv
AS42 XG0.5.csv
AS42 XG1.csv
AS42 XG1.5.csv
 

Names refer to solutions - each solution was composed of artificial seawater (AS) preraped according to a standard (ASTM, 2013. Standard Practice for  the Preparation of Substitute Ocean Water) (35 g/L) and recalclualted for salt content of 42 g/L and
dissolved polymer: XG - xanthan gum, in three concentrations 0.5 g/L, 1 g/L and 1.5 g/L.

3. Additional related data collected that was not included in the current data package: 
Data on settling of partices stored in 'MPs_sinking_dynamics' folder and physical properties of liquid columns stored in 'Density_and_refractive_index_profiles' folder.
	
4. Methodological information:
Description of methods used for collection/generation of data: 
Presented in a paper linked to this dataset.

5. Data-specific information:

*.csv files contain the following variables: 
- flow_properties:
variables stored in seven columns: shear rate [1/s], shear stress [Pa], viscosity [Pa s], speed [1/min], time [s],torque [µN m].
- amplitude_sweeps: 
variables stored in five columns: gamma - strain [%], tau - shear stress [Pa], StorageMod -storage modulus [Pa], Loss Mod - loss modulus [Pa], ComplVisc - Complex viscosity [Pa s].
