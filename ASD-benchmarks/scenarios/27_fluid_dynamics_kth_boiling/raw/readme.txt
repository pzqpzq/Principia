KTH/HWAT databank associated to the publication: Experimental investigation of the internal structure of boiling two-phase water flow under LWR core operating conditions
-----------------------------------------------------------------------------------

This repository contains the experimental data for the test conditions corresponding to Table 1 of the publication, saved in xml format.

The files contain the experimental boundary conditions, and all measured axial (pressure drop, wall temperatures) and radial profiles (void fraction, dynamic pressure, velocity and dispersed phase length scales) that can be used to validate computational codes, as described in the publications.

All parameter names in the files are explanatory.

SI units have been used, except for the dispersed phase length scales provided in mm. The inlet and wall temperatures are provided in Celsius.
