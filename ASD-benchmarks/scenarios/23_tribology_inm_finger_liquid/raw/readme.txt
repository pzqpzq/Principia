The data files in this repository are related to figures in the manuscript "A Touch of Stribeck - Finger-Pad Friction in Viscous Liquid Spreading".
Figure 2: Data in the file 'viscosity vs shear rate.dat'
Table 1:  Data in the file 'power law fit parameter.dat'
Figure 3 and Figure 5: Data in the file 'friction data.dat'
Figure 4: Data in the four files 'HeightHerseyIDxxsampleyy.dat'

Further information: Data for participants' finger-pad size and hydration: 'participant_hydration_size.dat'
Finger-pad hydration was measured by a corneometer (Courage + Khazaka, Cologne, Germany) in instrument units ranging from 0 to 120.
The finger-pad area was determined by analyis of photographs. The finger was positioned next to a reference scale with the pad facing upward, and a top-down photograph was taken. The reference scale was used to calibrate the image in ImageJ. Then, the finger pad segment was outlined using the "Polygon Selection" tool to determine its surface area.

Additionally, we provide the raw data for measured position and force of the finger pad for all trials in the file 'raw_data_position_force.dat'

All files have three header rows:
Row 1: Name of column
Row 2: Physical unit
Row 3: Comment
