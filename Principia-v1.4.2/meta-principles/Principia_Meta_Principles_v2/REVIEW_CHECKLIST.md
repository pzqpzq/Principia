# Publication Review Checklist

- [ ] The argument is a reusable relation, mechanism, theorem, limit, or governance rule—not a paper summary.
- [ ] Epistemic type and Principia kind are correctly separated.
- [ ] Boundary conditions include failure modes, not only applicability claims.
- [ ] At least one primary or authoritative work URL is inspectable.
- [ ] Award or industry recognition is recorded only as significance metadata.
- [ ] Mathematical notation uses dollar-delimited LaTeX.
- [ ] Relations use the current typed vocabulary and have compatible direction.
- [ ] No relation transfers truth, maturity, or theorem status automatically.
- [ ] Generation trace and content digest are retained.
- [ ] A domain expert has reviewed the scientific wording before Capsule promotion.
