Extraction protocol PBMCs were isolated from Healthy (n = 9), COVID-19 (n = 24), recovered (n = 16) and longitudinal recovered (n = 8) individuals. PBMCs were isolated using Histopaque®-1077 (Sigma-Aldrich) density gradient centrifugation. Samples were multiplexed using BD single cell multiplexing kit (Human), followed by tagging with a pool of 50 oligo-attached antibody for surface markers (Ab-Seq). Around 25000 cells were loaded per cartridge, followed by cell lysis, cDNA synthesis and final library preparation using BD WTA amplification kit as per manufacturer's recommendation. A poly-A transcripts library (WTA), Ab-Seq library and library from oligos of Sampe multiplexing kit (SMK) were constructed from each batch, and were sequenced on NovaSeq 6000 platform.
Library preparation was performed using the BD Rhapsody WTA amplification kit. Briefly, cDNAs were generated on cell capture beads from the BD Rhapsody cartridge. Ab-Seq and sample tag oligos were separated from Exonuclease I–treated beads by denaturation, while poly-A transcript cDNA remained bead-bound. Random priming and extension were performed on the beads, followed by Ampure XP cleanup, amplification, secondary Ampure XP cleanup, indexing, and a final dual-sided Ampure XP cleanup to generate the WTA library. Ab-Seq/sample tag oligos were amplified using universal oligos and cleaned with Ampure XP. The Ab-Seq library was prepared via index PCR and Ampure XP cleanup, whereas sample tag oligos were enriched by an additional PCR and Ampure XP cleanup. Finally, the SMK library was generated by index PCR of enriched sample tag oligos, followed by a final Ampure XP cleanup. Barcode sequences and batch-specific barcodes are provided in the supplementary file.
Following the final bead purification, all three libraries (per batch) were pooled in order to obtain a 30000 reads/cell for WTA library, 25000 reads/cell for Ab-Seq library and 360 reads/cell/sample tag/batch for the SMK library. Libraries of multiple batches were pooled based on the index sequences used during Index PCR steps.

Data processing The fastq files were generated follwed by demultiplexing using bcl2fastq, by using the index sequence used during index PCR steps. The read 1 and read 2 fastq files were then processed using WTA analysis pipeline and aligned to GRCh38 and GencodeV47 for transcript annotation and quantitation.
Further processing was done with Seurat (v5.3.0) (cell and gene filtering, clustering, differential gene expression analysis).
Microbial count matrices were generated via PathogenTrack pipeline.
