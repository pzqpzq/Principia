# Legacy releases

The actively maintained framework is [`Principia-v1.3/`](../Principia-v1.3/).
These snapshots are retained for historical reference and are not part of the
current `principia-ai` package:

- [`v1.2/`](v1.2/) — the former visual workbench and GitHub-native cloud
  interface;
- [`v1.0/`](v1.0/) — the first product-oriented local release;
- [`v0-demo-jun8-v2/`](v0-demo-jun8-v2/) — the early demonstration release.

Follow the README and license inside each snapshot. Legacy generated databases,
machine-local manifest pointers, caches, and credentials are intentionally not
carried into the current branch; their historical commits remain available in
Git history.
