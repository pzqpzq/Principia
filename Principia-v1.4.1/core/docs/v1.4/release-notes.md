# Principia 1.4.0 release notes

Principia 1.4.0 adds a packaged local product UI, immutable Global Principle packages, unified Global/Local search and bounded graphs, reversible Scenario Mode, persistent Local Discovery jobs with explicit model-egress policies, generated OpenAPI clients, and backup-first v1.3 workspace migration.

Compatibility is deliberate: legacy public imports, data, IDs, workspace database filename, and CLI workflows remain valid. New scientific objects distinguish unassessed Candidates from reviewed Capsules.

The release includes full `.pcp` install/update/verify/pin/rollback and offline operation. `.pcd` delta packages, real scientific-area publication, GitHub publication, and package-index publication are outside this implementation boundary.
